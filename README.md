# Portfolio OS

Same concept as the Design OS. Different goal.

The Design OS gave Claude context about a design project. This one gives Claude context about you and your portfolio site. The pattern is identical: a CLAUDE.md that sets the rules, folders that hold the material, skills that do the work.

---

## Folder structure

```
portfolio-os/
  CLAUDE.md                         <- Fill this in first. Everything else depends on it.
  README.md                         <- This file.
  .claude/
    skills/
      case-study/                   <- Turns project material into a PRIME case study
      visual-direction/             <- Extracts visual rules from Figma or image references
  00 Context/
    bio.md                          <- 2-3 sentences about you. Claude reads this for copy.
    visual-direction.md             <- Generated by /visual-direction. Loaded every session.
  01 Projects/
    [project-name]/
      raw/                          <- Drop anything here: docs, screenshots, briefs, links
      case-study.md                 <- Generated by /case-study. Iterate from here.
  02 Site/
    index.html                      <- Homepage
    case-study.html                 <- Case study page template
    about.html                      <- About page
    style.css                       <- Shared styles
```

---

## Step 1: Fill in CLAUDE.md

Open CLAUDE.md. Fill in every section. This is your brief to Claude Code. The more specific it is, the less Claude guesses.

Pay particular attention to:
- What kind of work you want to attract (specific beats vague)
- The Do NOT list (name what you do not want before Claude adds it)

The Visual rules section is generated by /visual-direction and lives in 00 Context/visual-direction.md. CLAUDE.md loads it automatically every session.

---

## Step 2: Fill in 00 Context/bio.md

Two or three sentences. This is what Claude reads when generating about page copy and any intro text across the site. Write it in the same tone you want the site to have.

---

## Step 3: Set your visual direction

Two options:

**Option A: You have an existing Figma file or design system**
Run `/visual-direction` in Claude Code. Provide the Figma file URL. Claude extracts colors, typography, spacing, and component style, and writes the rules into 00 Context/visual-direction.md.

**Option B: You have visual references**
Run `/visual-direction` in Claude Code. Share screenshots, URLs, or images of sites or designs you want to draw from. Claude extracts what makes them look the way they do and writes concrete rules into 00 Context/visual-direction.md.

---

## Step 4: Generate the site structure

Once CLAUDE.md and 00 Context/visual-direction.md are filled in, prompt Claude Code:

```
Read CLAUDE.md and 00 Context/bio.md.
Generate the portfolio site structure: index.html, case-study.html, about.html, and style.css.
Save all files to 02 Site/.
Placeholder content only. No real text yet. Structure and layout only.
```

Open index.html in a browser. If it looks intentional, move on.

---

## Step 5: Write your case studies

For each project you want to include:

1. Create a folder in 01 Projects/ named after the project
2. Drop any material you have into 01 Projects/[project-name]/raw/
3. Run `/case-study` in Claude Code
4. Feed Claude the material and iterate on the output
5. The final draft saves to 01 Projects/[project-name]/case-study.md

---

## Step 6: Integrate and push

Once you have a site structure and at least one case study draft, use the Code Brief to integrate the content into the site. Commit. Push. The rest of the week is iteration.

---

## Skills

| Skill | What it does | When to run |
| --- | --- | --- |
| `/site-brief` | Asks structured questions about layout, navigation, animation and references, saves concrete decisions to 00 Context/site-brief.md | On Monday, before /visual-direction |
| `/visual-direction` | Extracts visual rules from Figma or image references, saves to 00 Context/visual-direction.md | On Monday, after /site-brief |
| `/case-study` | Generates a PRIME case study from any project material | Once per project, on Wednesday |
